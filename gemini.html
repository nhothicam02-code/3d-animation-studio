GOOGLE GEMINI

Kết nối Gemini API

Nhập API key để Studio có thể chuyển mô tả tiếng Việt thành chuyển động cho nhân vật Mixamo. Key được lưu trong bộ nhớ trình duyệt này và dùng chung với trang Studio.

Chưa kiểm tra kết nối. Hãy lưu key rồi bấm “Kiểm tra kết nối”.
Lưu ý bảo mật: trang web chạy trực tiếp trên trình duyệt nên API key có thể bị xem trong công cụ dành cho nhà phát triển hoặc lưu lượng mạng. Không dùng key có quyền truy cập nhạy cảm trên website công khai; hãy giới hạn key và thu hồi nếu bị lộ.
